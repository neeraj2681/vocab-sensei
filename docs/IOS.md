# iPhone app

The iPhone app is the web app inside a native shell, built with [Capacitor](https://capacitorjs.com) (MIT).
It loads the live site, so every deploy reaches the phone without a rebuild, and it adds what Safari can't do:

- **Haptics**: real taps for right and wrong answers (`@capacitor/haptics`).
- **On-device speech** for "Say it": Apple's speech recognition on the phone, in the phone's English
  (en-IN, en-GB…), hinted with the expected word. Our own small plugin: `frontend/ios/App/App/SpeechPlugin.swift`.
  The server still judges what was heard, exactly as on the web.

Not yet:

- **Push reminders** need Apple's push service, which needs the paid Apple Developer Program ($99/year).
- **Home-screen widget**: the next step.

## Install on your iPhone (free Apple ID)

One-time setup:

1. **Xcode → Settings → Accounts**: add your Apple ID (a free one is fine).
2. On the iPhone: **Settings → Privacy & Security → Developer Mode → On** (it restarts).
3. In `frontend/`, create `.env.ios.local` (not committed) with the site's address:

   ```
   VOCAB_APP_URL=https://your-site-address
   ```

Each time you build:

```bash
cd frontend
npm ci              # first time, or after dependencies change
npm run ios:sync    # builds the web app and copies settings into the iOS project
npm run ios:open    # opens Xcode
```

In Xcode:

1. Click **App** (blue icon, top left) → target **App** → **Signing & Capabilities** → **Team**: your name
   (Personal Team). If Xcode says the bundle identifier is taken, change it to something unique,
   e.g. `io.github.<you>.vocabsensei`.
2. Plug in the iPhone (or pick it over Wi-Fi), choose it at the top, press **▶ Run**.
3. The first time, the iPhone asks you to trust the developer: **Settings → General → VPN & Device
   Management → your Apple ID → Trust**.

With a free Apple ID the app works for **7 days**; then run it from Xcode again. The paid program removes
that limit and allows TestFlight and the App Store.

When the site moves to a new address (e.g. your own domain), change `VOCAB_APP_URL`, run `npm run ios:sync`
and run the app from Xcode again.

## Notes

- **Simulator**: on a Mac that serves the site over Tailscale, the simulator can't reach the Tailscale
  address. Use `VOCAB_APP_URL=http://localhost:8080` for simulator tests (plain `http` is allowed only for that).
- **Changing native code**: Swift files must be listed in `App.xcodeproj` (add them in Xcode, or copy how
  `SpeechPlugin.swift` is listed). Plugins of our own are registered in `MainViewController.swift`.
- `ios/App/App/public` and `capacitor.config.json` are generated by `npm run ios:sync` and not committed.
